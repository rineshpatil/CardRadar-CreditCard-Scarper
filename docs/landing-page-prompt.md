# Prompt: Rebuild the CardRadar landing page

> Paste everything below the line into Claude Code, run from the repo root `E:\Project\CardRadar`.

---

You are a senior front-end engineer and product designer. Rebuild the CardRadar landing page (`public/index.html`) into an interactive, high-conversion landing page that shows off the real card data. It must feel premium and alive, and it must still be fast, accessible and honest.

## Context (read before planning)

- **Product:** CardRadar is a free guide to Indian credit cards: 143 cards from 25 banks, with fees, rewards, lounges, eligibility and a **Verified / May be outdated / Unverified** label on every card, checked against the bank's own page by a weekly crawl. Read `docs/product-spec.md` and `README.md` first.
- **Stack (fixed):** static HTML + CSS + plain JavaScript, no framework, no build step, **no npm dependencies**. Hosted on S3 + CloudFront. Local server: `npm run dev` → http://localhost:3000.
- **Data:** `public/data/cards.json` (generated by `npm run build` from `data/cards/*.json`). Each card has `id, name, bank, network, category, tier, isLTF, isCoBranded, annualFee, joiningFee, rewardRate, applyUrl, image, benefits{cashback, lounges{airport{domestic,international}, railway{count}}, golf, fuel, dining, movies, forex{markupFee}}, eligibility{minIncome}, highlights, popularityScore, verificationStatus, lastVerifiedAt`. Lounge count `-1` means unlimited. 103 cards have a bank photo in `public/img/cards/`; the rest have no image.
- **Reuse, don't rewrite** (`public/lib.js`): `escapeHtml`, `safeUrl`, `queryCards`, `computeStats`, `bankCounts`, `recommend` (the quiz ranking), `verificationBadge`. `public/app.js` owns the chat widget; `public/account.js` owns sign-in and PRO checkout; `public/tools.js` owns card tilt, compare and the full quiz (`/dashboard.html#quiz` opens it).
- **Design system (keep it):** tokens in `:root` of `public/styles.css` — near-black `--bg-primary #05060d`, cyan `--accent-primary #00f0ff`, magenta `--accent-pink #ff2bd6`, lime `--accent-secondary #b6ff3b` (lifetime free), amber `--accent-gold #ffb800` (premium); Space Grotesk headings, Inter body; existing light theme toggle. Use the tokens, never hard-coded colours.
- **Business rules:** Catalog, filters, quiz and 2-card compare are free. **PRO = ₹99/month or ₹999/year**: unlimited CardRadar AI and 4-card compare. Free accounts get **3 AI answers a day**, and the AI needs sign-in. No affiliate links, no in-site applications, not financial advice.
- **Problems with the current page (fix all):** a 4-second splash screen blocks the page; perk "3D" icons are emoji inside SVG; the hero shows empty placeholder shapes instead of real cards; the AI section says "no sign-up needed" (wrong); the fake chat recommends cards without checking they exist; there is no pricing, no trust/verification story, no FAQ, and only one interactive element.

## Sections to build (in this order)

Every number, card name and card image shown must come from `cards.json` at runtime. Never hard-code stats or invent cards.

1. **Sticky nav:** logo, links (Cards, Card finder, Compare, AI, Pricing, FAQ), theme toggle, account button from `account.js`, "Browse cards" CTA. Collapses to a menu button under 768px. Highlights the current section while scrolling.
2. **Hero:**
   - Headline + one-line value proposition + primary CTA "Find my card" (scrolls to section 4) + secondary CTA "Browse all cards" (`/dashboard.html`).
   - **Live stats**: cards, banks, lifetime-free count, verified count, using `computeStats`, counting up once when visible.
   - **3D card stack**: a fan of 5 real card photos (top `popularityScore` cards that have an `image`) that tilts with the pointer and cycles every few seconds. Clicking a card opens it on the dashboard.
   - **Quick search**: a type-ahead over card name and bank (max 6 suggestions, keyboard navigable, ARIA combobox). Picking one goes to the dashboard.
3. **Bank marquee:** an infinitely scrolling strip of bank names with their card counts (`bankCounts`). Text only, no bank logos. It pauses on hover and is static when reduced motion is on.
4. **"Find your card in 30 seconds": inline mini-quiz.** The same 4 questions as the full quiz (income, top spend, fee budget, lounges matter). Use chip buttons and a progress bar, one question at a time. Results show the top 3 from `recommend()` with card photo, fee, the reasons it matched, and a verification badge, plus a "See all 5 matches" link to `/dashboard.html#quiz`. Answers never leave the browser.
5. **Category explorer:** tabs for Lifetime free, Lounge access, Cashback, Travel & zero forex, Fuel, Railway, Golf, Super premium. Each tab shows a horizontally scrollable, snap-aligned row of real cards using `queryCards`: photo or neon fallback face, name, bank, annual fee, one highlight. A "View all N" link at the end opens the dashboard with that filter. Tabs follow the WAI-ARIA tabs pattern with arrow-key support.
6. **Reward calculator: "What is a card worth to you?"** Sliders for monthly spend (online shopping, dining, groceries, fuel, travel), shown in ₹ with Indian digit grouping. It estimates yearly rewards minus annual fee for every card whose `rewardRate` parses to a number, and shows the top 3 with a bar chart made from plain divs. Label it clearly: "Rough estimate from the headline reward rate. Caps, exclusions and milestones not included." Skip cards whose rate can't be parsed.
7. **Lifetime free vs premium:** an interactive toggle or split view with live counts, median fee, lounge share and 3 example cards per side.
8. **Compare teaser:** two searchable selects. Picking 2 cards shows a mini side-by-side (annual fee, reward rate, domestic/international lounges, forex markup, verification) with the better value highlighted, and a "Full comparison" link to the dashboard. Mention that PRO compares up to 4 cards.
9. **"Data you can trust":** explain the three verification labels with live counts for each, the weekly check against the bank's page, the source quotes, and the rule that nothing goes live without review. Include one real example card's badge. Keep it plain and short.
10. **CardRadar AI:** an auto-playing, scripted chat demo that types out one question and an answer built from real data (e.g. "Best lifetime-free card with lounge access?" answered from `queryCards`). It plays once when visible and has a replay button. State the real rules: sign in, 3 free answers a day, unlimited with PRO, answers only from CardRadar's card list and flags unverified data. CTA opens the existing chat widget.
11. **Pricing:** Free vs PRO cards with a Monthly/Yearly toggle (₹99 / ₹999, show "save 16%"). PRO CTA calls the existing `account.js` subscribe flow; Free CTA goes to the dashboard.
12. **How it works:** 3 steps (answer 4 questions → compare → apply on the bank's own site).
13. **FAQ:** 6–8 questions using native `<details>/<summary>`. Cover: Is it free? Where does the data come from? What does "Unverified" mean? Do you earn from applications? (No.) Do you store my income or quiz answers? (No.) What does PRO include? Is this financial advice? (No.) Add `FAQPage` JSON-LD.
14. **Final CTA band + footer:** repeat "Find my card", nav links, placeholder links for Terms / Privacy / Refund policy, and the existing disclaimer text.

Keep the existing chat FAB and panel markup and scripts working on this page.

## Motion and polish

- Use CSS for motion where possible: scroll-reveal via one shared `IntersectionObserver`, 3D tilt via CSS transforms, and `transform`/`opacity` animations only.
- Wrap all non-essential motion in `@media (prefers-reduced-motion: no-preference)`. With reduced motion the page is fully usable and static.
- Replace the 4-second splash with nothing, or with a splash of at most 600 ms shown only on the first visit (`sessionStorage`) that any click or keypress skips.
- Use a subtle animated radar sweep / grid glow in the hero background (CSS only). No emoji used as icons. Use inline SVG icons.

## Constraints (MUST)

- **Files you may change:** `public/index.html`, `public/landing.js`, a new `public/landing.css` for landing-only styles, and old landing-only rules in `public/styles.css` (delete the dead ones you replace: splash, perk-float, floating-card, radar-scan, compare-box, chatbot-mockup, and so on, after grepping that `dashboard.html` doesn't use them).
- **Dashboard deep links:** `public/tools.js` only handles `#quiz` today. If you need `#filter=<name>` or `#card=<id>` links, add the smallest handler in `public/app.js`/`tools.js` that applies them. Change nothing else on the dashboard.
- Escape all card text with `escapeHtml`; render links only through `safeUrl`. No `innerHTML` with unescaped data.
- No new dependencies, CDNs, frameworks, analytics or trackers. The only allowed external request is the existing Google Fonts import.
- No fabricated content: no fake testimonials, user counts, ratings, "as seen in" logos or bank logos.
- Honest copy: no "best card in India" claims of your own, and no "guaranteed approval".
- Card images: `loading="lazy"` with explicit `width`/`height`, except the hero stack (`fetchpriority="high"` on the first one). Cards without an image use the existing neon fallback face.
- The page renders its shell (nav, hero text, CTAs) before `cards.json` loads. Show skeletons, then fill in. If the fetch fails, show a short error with a retry button and keep the static content.
