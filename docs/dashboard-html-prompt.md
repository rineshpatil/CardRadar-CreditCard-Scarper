## Context (read before planning)

- **Product:** CardRadar is a free guide to Indian credit cards: 143 cards from 25 banks, each with a **Verified / May be outdated / Unverified** label checked against the bank's own page by a weekly crawl. Read `docs/product-spec.md` (sections 4 and 5 describe this page's features and flows) and `README.md`.
- **Stack (fixed):** static HTML + CSS + plain JavaScript, no framework, no build step, **no npm dependencies**, no chart library. Scripts load as globals in this order: `lib.js`, `app.js`, `account.js`, `tools.js`. Local server: `npm run dev` → http://localhost:3000. Tests: `npm test` (`node --test`, includes `test/lib.test.js`).
- **Data:** `public/data/cards.json` (generated by `npm run build`). Card fields: `id, name, bank, network, category, tier (entry|mid|premium|super_premium|private), isLTF, isCoBranded, annualFee, joiningFee, rewardRate` (a string such as `"3.3%"`, not always parseable), `applyUrl, image` (103 of 143 cards; the others use the neon fallback face from `renderCardVisual`), `benefits{cashback{description,details[]}, lounges{airport{domestic,international,description}, railway{count}}, golf, fuel, dining, movies, forex{markupFee}, other[]}, eligibility{minIncome,minAge}, highlights[], popularityScore, sources[], verification{}` (source quotes), `verificationStatus, lastVerifiedAt, lastCheckedAt, hasPendingChanges`. A lounge count of `-1` means unlimited.
- **What exists and must keep working:**
  - `public/lib.js` (pure, unit-tested): `FILTERS`, `queryCards`, `computeStats`, `bankCounts`, `verificationBadge`, `recommend`, `escapeHtml`, `safeUrl`, `renderMarkdown`.
  - `public/app.js`: theme toggle, `loadCards`, card rendering (`renderCardHTML`, `renderCardVisual`), bank chips, stats, the card-details modal (`renderModalContent`), toasts, and the AI chat.
  - `public/account.js`: sign-in and PRO checkout (`openAccount`, `subscribe`). The UI reads the plan from `accountInfo`.
  - `public/tools.js`: 3D tilt and flip, compare tray and table (**2 cards free, 4 with PRO**; going over opens Go PRO), the 4-question quiz (`#quiz` opens it), and `revealOnScroll`.
- **Design system (keep and refine):** tokens in `:root` of `public/styles.css`: bg `--bg-primary #05060d`, cards `--bg-card`, cyan `--accent-primary #00f0ff`, magenta `--accent-pink #ff2bd6`, lime `--accent-secondary #b6ff3b` (lifetime free), amber `--accent-gold #ffb800` (premium), plus the radius, shadow and glow tokens. Space Grotesk for headings and numbers, Inter for body text, and a light theme. Use tokens only; add new tokens to `:root` (and the light theme) rather than hard-coding colours.
- **Problems with the current page (fix all):** it's one long scroll (hero → stats → bank chips → filter bar → grid), so the cards start far below the fold; emoji are used as icons everywhere; only one benefit filter can be active at a time; there's no fee range, network or "cards I can get" filter; there's no list or table view; filters aren't in the URL, so they can't be shared and Back doesn't work; the details modal has no deep link and no next/previous; the stats are decoration, not controls; there's no shortlist; the empty state is a dead end.

## Layout (app shell)

- **Top bar (sticky):** logo (links to `/`), global search (press `/` to focus; suggestions for cards, banks and benefits), "Find my card" (opens the quiz), theme toggle, AI chat button, account button showing a **PRO** badge when subscribed.
- **Left filter rail** (desktop ≥ 1024px, sticky, scrolls on its own). On mobile and tablet it becomes a **Filters** button with a live count that opens a bottom sheet (focus-trapped, closes with Esc, has an "Apply / Show N cards" button).
- **Main column:** insights panel → results toolbar → results.

## Features to build

1. **Insights panel ("Radar"), collapsible and remembered per viewer.** Every tile and chart is also a filter: clicking it applies that filter, and the active one stays highlighted.
   - Stat tiles from `computeStats`: total, lifetime free, lounge, golf, cashback, banks, plus a verified count. Numbers count up on first load only.
   - **Annual fee distribution:** a bar chart with buckets Free / ≤ ₹1,000 / ≤ ₹5,000 / ≤ ₹10,000 / > ₹10,000. Clicking a bar sets the fee range.
   - **Cards by bank:** horizontal bars for the top 8 banks, plus "+N more" that opens the bank filter.
   - **Network split** (Visa, Mastercard, RuPay, Amex, Diners) and a **verification** ring (verified / may be outdated / unverified).
   - Charts are hand-built SVG or divs using tokens, with accessible names and a keyboard-focusable tooltip, and every chart has a visually hidden data table. **The charts reflect the current filtered set**, so the panel doubles as a live summary.
2. **Filters (rail / sheet), combinable with AND across groups:**
   - Benefits as multi-select toggles: Lifetime free, Premium, Airport lounge, Railway lounge, Golf, Cashback, Zero forex, Fuel waiver, Dining, Movies.
   - Banks as a searchable multi-select with counts from `bankCounts`.
   - Network, and tier (Entry → Invite only).
   - Annual fee range slider (₹0 to the max in the data), shown with Indian digit grouping (`Intl.NumberFormat('en-IN')`).
   - "**Cards I can get**": the user types a yearly income, and cards whose `eligibility.minIncome` is above it are hidden. The income stays in the browser and is never sent anywhere.
   - "Verified only" and "Hide co-branded".
   - Every option shows how many cards it would leave; options that would give 0 results are disabled rather than hidden.
3. **Results toolbar:** "N of 143 cards", active filter pills (each removable with ×) and "Clear all", sort (Popularity, Fee low→high, Fee high→low, Reward rate, Name, Bank), a **view switcher: Grid / List / Table**, and a Bank cards / Co-branded / All segmented control that replaces the two separate sections.
4. **Grid view:** a refined card tile with:
   - the card photo, with the existing tilt, glare and flip from `tools.js`
   - name, bank, network, the LTF or Premium badge, and the verification badge
   - annual fee, reward rate, and 4 benefit icons with tooltips
   - buttons for **Compare**, **Save** and **Details**
   - a staggered entrance animation.
5. **List view:** dense rows with a thumbnail, name/bank, fee, reward rate, benefit icons, status and actions. Good for scanning on mobile.
6. **Table view:**
   - Sortable columns: name, bank, annual fee, joining fee, reward rate, domestic lounges, international lounges, forex markup, minimum income, status.
   - Sticky header and first column; scrolls horizontally inside its own container on small screens.
   - Header clicks change the sort, with `aria-sort`.
7. **Card details:**
   - **Layout:** a right-side drawer on desktop and a full-screen sheet on mobile, replacing the centred modal. Reuse the content logic from `renderModalContent`.
   - **Tabs:** Overview · Fees & rewards · Lounges & travel · Eligibility · Sources. The Sources tab shows the verified quotes from `verification` with links and the last-checked date.
   - **Navigation:** ← / → keys and buttons step through the current result list.
   - **Similar cards:** up to 3 cards with the same tier or category.
   - **Apply:** "Apply on bank's site" opens `applyUrl` through `safeUrl`, with `rel="noopener noreferrer"` and a one-line "You're leaving CardRadar" note.
   - **Deep links:** the drawer can be opened directly with `#card=<id>`.
8. **Shortlist:** Save (heart) adds a card to a shortlist stored in `localStorage`, wrapped in try/catch so the page works if storage is blocked. The top bar opens a shortlist drawer, from which you can send the saved cards to Compare (limits still apply).
9. **Compare:** keep the existing tray and table from `tools.js`, restyled to match. Show the limit clearly ("2 of 2, PRO compares up to 4") before the user hits it.
10. **Shareable state:** all filters, sort, view and search sync to the query string (`?benefits=lounge,golf&banks=HDFC%20Bank&fee=0-5000&sort=fee-low&view=table&q=...`) with `history.replaceState`, and opening the drawer uses `pushState`, so Back closes it. Loading a URL restores that exact state. Keep `#quiz` working, and accept `#filter=<name>` as an alias so links from the landing page work.
11. **States:** skeletons that match the chosen view while loading. A useful **empty state**: "No cards match", then suggestions such as "Remove *Golf* → 12 cards" computed from the data, plus Clear all. An error state with Retry if `cards.json` fails.
12. **Keyboard:** `/` focuses search, Esc closes the top-most layer, ← / → move between cards in the drawer, and every control can be reached with Tab and shows a visible focus ring.

## Aesthetic direction

- A premium dark fintech feel built on the existing neon system: layered glass panels (`--bg-glass`, subtle borders, `backdrop-filter` with a solid fallback), a faint grid background, and glow used only on focus, hover and active states, never on everything at once.
- Clear hierarchy: one accent (cyan) for actions, lime only for lifetime free, amber only for premium, magenta sparingly for highlights. Numbers use Space Grotesk with `font-variant-numeric: tabular-nums`.
- An 8px spacing scale and consistent radius tokens. Card tiles have equal heights and aligned baselines across the grid.
- **Replace every emoji icon with one inline SVG sprite** (`<svg><symbol>` in `dashboard.html`), used through `<use href="#icon-…">`. Covers the benefits, filters, sort, views, theme, save, compare and close icons.
- Motion: 150–250 ms ease-out, `transform`/`opacity` only, and everything non-essential inside `@media (prefers-reduced-motion: no-preference)`.
- Both themes must look intentional. Check light mode contrast as carefully as dark.
